# PADATI — Pariaman Digital Industri

Pengumpulan data unit usaha berbasis **web scraping** dari platform e-commerce (GoFood, Shopee, Tokopedia, Blibli, Lazada) untuk pemetaan ekonomi digital Kota Pariaman dalam rangka **Sensus Ekonomi 2026**.

Dikembangkan oleh **BPS Kota Pariaman** menggunakan SE Merchant Extension dan dashboard pengolahan berbasis Streamlit.
